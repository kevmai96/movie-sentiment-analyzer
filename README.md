# Movie sentiment analyzer

# What is it
This is a practice project that performs sentiment analysis on movie reviews. It classifies reviews as Positive or Negative using three different machine learning models:

  - Naive Bayes
  - Logistic Regression
  - Linear SVM

# How to test:
1. Setup environment
python3.9 -m venv env
source env/bin/activate

2. Install requirements:
pip install -r requirements.txt
    
3. Run: python app.py

# IMPORTANT DISCLAIMER
This project is for practice and learning purposes only.
The predictions made by the models are not guaranteed to be accurate and should not be used for real-world decisions.
The dataset is limited and may not reflect real movie review sentiment comprehensively.
